# cPanel-এ OKExPay পেমেন্ট গেটওয়ে সেটআপ নির্দেশিকা

এই ফোল্ডারে আপনার মার্চেন্ট আইডি `5393` এবং মার্চেন্ট কি `d8490b215ef5248d7fb693a101f9898d` দিয়ে সম্পূর্ণ প্রস্তুতকৃত PHP স্ক্রিপ্টগুলো রয়েছে।

---

## ১. ফাইল পরিচিতি
- **`config.php`**: মার্চেন্ট ক্রেডেনশিয়ালস, সিগনেচার হ্যাশিং ও কনফিগারেশন।
- **`collect.php`**: বিকাশ ও নগদে পেমেন্ট অর্ডার তৈরি ও ক্যাশিয়ারে রিডাইরেক্ট করে।
- **`notify.php`**: গেটওয়ের কলব্যাক (Webhook) গ্রহণ করে, সিগনেচার যাচাই করে এবং `success` রিটার্ন দেয়।
- **`order_status.php`**: ইউজার পেমেন্ট করেছে কিনা তা চেক করার এপিআই।

---

## ২. cPanel-এ আপলোড করার নিয়ম:

1. আপনার cPanel-এ লগইন করুন।
2. **File Manager** ওপেন করুন।
3. **`public_html`** ফোল্ডারে প্রবেশ করুন।
4. একটি নতুন ফোল্ডার তৈরি করুন, নাম দিন: **`gateway`** (বা আপনার পছন্দমতো নাম)।
5. এই ফোল্ডারের ফাইলগুলো (`config.php`, `collect.php`, `notify.php`, `order_status.php`) সেখানে আপলোড করুন।

---

## ৩. আপনার গেটওয়ে লিঙ্কসমূহ:

ধরা যাক আপনার ডোমেন `example.com`:
- **রিচার্জ তৈরির লিঙ্ক**: `https://example.com/gateway/collect.php`
- **কলব্যাক / Webhook লিঙ্ক (এজেন্টকে দেওয়ার জন্য)**: `https://example.com/gateway/notify.php`
- **অর্ডার চেক লিঙ্ক**: `https://example.com/gateway/order_status.php?out_trade_no=...`

---

## ৪. চাইনিজ এজেন্ট / কাস্টমার ম্যানেজারকে কী বলবেন:
OKExPay ম্যানেজারের টেলিগ্রাম বা সাপোর্টে জানান:
> "Please whitelist my domain and IP for Merchant ID 5393. My notify callback URL is: https://yourdomain.com/gateway/notify.php"

তারা আপনার ডোমেনটি সিস্টেমে বাইন্ড করে দিলে আপনার অ্যাকাউন্ট সরাসরি লাইভ হয়ে যাবে।
